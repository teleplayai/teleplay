# Teleplay

**The AI game maker. Create playable worlds with a sentence.**

[Teleplay](https://www.teleplay.ai) turns one sentence into a game you play in your browser, in 2D or 3D (beta), alone or with friends by link. A bot plays every game before you get it, each game has its own art, music and sound, and you can change it by chatting.

This repository is where you can tell us what's broken and what you'd like to see. **Teleplay's code is not here**, and this is not a place for account questions.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml) and tell us:

- what you did, what you expected, and what happened instead;
- the game's link, if the game is set to *Anyone with the link* or is on Discover;
- your browser and device.

Please **don't post personal information** (your email, real name or anything private) or other people's games without their permission.

## Suggest an idea

[Open an idea](../../issues/new?template=idea.yml). One idea per issue makes it easier for us and others to follow.

## Security problems

Please don't report security problems here. See [SECURITY](https://github.com/teleplayai/.github/blob/main/SECURITY.md).
